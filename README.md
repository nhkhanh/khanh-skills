# khanh-skills

Reusable Claude Code configuration.

- [CLAUDE.md](CLAUDE.md) — boilerplate project instructions. Copy to `.claude/CLAUDE.md` in a new project and replace every `{{PLACEHOLDER}}`.
- [rules/](rules/) — shared rules, indexed in [rules/MEMORY.md](rules/MEMORY.md). Copy to `.claude/rules/` next to the CLAUDE.md. [rules/numbering.md](rules/numbering.md) applies to every response and skill.
